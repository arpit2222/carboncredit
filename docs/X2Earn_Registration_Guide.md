# VeBetter DAO X2Earn App Registration Guide

## Overview

This guide provides step-by-step instructions for registering the VeChain Carbon Credit System as an X2Earn application with VeBetter DAO to receive B3TR token funding for sustainability rewards.

## What is X2Earn?

X2Earn (Experience to Earn) is VeBetter DAO's program that rewards users with B3TR tokens for participating in sustainability-focused applications. By registering as an X2Earn app, our carbon credit system can receive funding to reward users for their environmental contributions.

## Prerequisites

Before registering, ensure you have:

1. **Deployed Smart Contracts**: All contracts deployed on VeChain mainnet
2. **B3TR Token Contract**: Access to B3TR token (0x5ef79995FE8a89e0812330E4378eB2660ceDe699)
3. **VeBetter DAO Account**: Active account on VeBetter DAO platform
4. **Project Documentation**: Complete project description and technical details
5. **Sustainability Impact Metrics**: Clear metrics showing environmental impact

## Registration Process

### Step 1: Prepare Application Materials

#### 1.1 Project Overview
```
Project Name: VeChain Carbon Credit System
Category: Environmental Sustainability
Description: Blockchain-based carbon credit tracking and trading system that incentivizes environmental conservation through B3TR token rewards
```

#### 1.2 Technical Specifications
- **Blockchain**: VeChain Thor
- **Smart Contracts**: 6 deployed contracts
- **Token Integration**: B3TR token rewards
- **Fee Delegation**: VIP-191 support for gasless transactions
- **NFT Standard**: ERC-721 for carbon credits

#### 1.3 Sustainability Impact
- **Carbon Tracking**: Real-time carbon credit generation and verification
- **Environmental Incentives**: B3TR rewards for carbon credit creation
- **Transparency**: Immutable blockchain records of environmental contributions
- **Accessibility**: Gasless transactions for broader participation

### Step 2: Access VeBetter DAO Platform

1. Visit [VeBetter DAO](https://vebetter.io)
2. Connect your VeChain wallet (VeWorld, Sync2, etc.)
3. Navigate to the X2Earn section
4. Click "Register New App" or "Apply for Funding"
