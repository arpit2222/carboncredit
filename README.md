# VeChain Carbon Credit NFT System

## Overview
A comprehensive blockchain-based carbon credit tracking system built on VeChain, featuring both a Next.js frontend and complete smart contract backend. This project tokenizes carbon credits as NFTs, enabling transparent verification, trading, and retirement of carbon offsets generated by farmers and organizations.

## 🌟 Live Demo
- **Frontend**: [carboncredit-eight.vercel.app](https://carboncredit-eight.vercel.app)
- **VeChain Testnet**: All contracts deployed and tested

## 🏗️ Architecture

### Frontend (Next.js)
- **Modern UI**: Built with Next.js 14, React, and Tailwind CSS
- **Responsive Design**: Mobile-first approach with beautiful animations
- **Component Library**: Reusable UI components with shadcn/ui
- **Pages**: Landing, Dashboard, Marketplace, Alliance, and Qualification pages

### Backend (VeChain Smart Contracts)
Complete production-ready smart contract system with:

#### ✅ **Phase 1: Core NFT Contract**
- **ERC-721 Carbon Credit NFTs** with rich metadata
- **Role-based access control** (Minter, Burner, Admin roles)
- **IPFS integration** for verification documents
- **Retirement mechanism** for carbon offsetting

#### ✅ **Phase 2: Identity Management**
- **OrganizationRegistry**: Manage organization profiles and verification
- **FarmerRegistry**: Track farmer profiles and land information
- **KYC Integration**: Document verification and status tracking

#### ✅ **Phase 3: Verification System**
- **Multi-step verification workflow**
- **Status management** (Pending, Verified, Rejected, Retired)
- **Event emission** for transparency

#### ✅ **Phase 4: Fee Delegation (VIP-191)**
- **Gasless transactions** for users
- **Sponsor management** system
- **Delegation policies** (Public, Whitelist, Conditional)
- **Gas usage tracking** and limits

#### ✅ **Phase 5: VeBetter DAO Integration**
- **B3TR token rewards** for carbon credit generation
- **Automatic reward calculation** based on carbon amount
- **Verification bonuses** (150% for verified credits)
- **Claim system** for users

#### ✅ **Phase 6: Cross-Chain Bridge**
- **Wanchain XFlows integration** for cross-chain transfers
- **Bridge status tracking** and event management
- **Multi-chain support** (Ethereum, Polygon, BSC, etc.)

#### ✅ **Phase 7: JavaScript SDK**
- **Complete SDK** for contract interactions
- **VeWorld wallet integration**
- **IPFS utilities** for metadata management
- **Helper functions** for common operations

## 🚀 Quick Start

### Frontend Development
```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Open http://localhost:3000
```

### Backend Development
```bash
# Install dependencies
npm install

# Compile contracts
npm run compile

# Run tests
npm test

# Deploy to testnet
npm run deploy:testnet
```

## 🔧 Configuration

### Environment Variables
Copy `env.example` to `.env` and configure:

```bash
# VeChain Private Keys (without 0x prefix)
PRIVATE_KEY_TESTNET="your_private_key_here"
PRIVATE_KEY_MAINNET="your_private_key_here"

# Or use mnemonic phrases
MNEMONIC_TESTNET="your mnemonic phrase here"
MNEMONIC_MAINNET="your mnemonic phrase here"

# IPFS Configuration
IPFS_API_KEY="your_ipfs_api_key"
PINATA_API_KEY="your_pinata_api_key"

# Network Configuration
VECHAIN_NETWORK=testnet
```
